# Путь Стратегии

Проект исследования древнекитайских классических текстов как единой системы, построенной на космологии У-Син (五行).

## Шесть групп корпуса

- **兵略** — стратегические трактаты (Сунь-Цзы, Лю Тао и др.)
- **治術** — тексты об управлении
- **宇宙秩序** — космологические тексты
- **五失典籍** — утраченные книги
- **身·文** — тело и культура
- **器·符** — инструменты и символы

## Четыре основания

Система опирается на метод 一二三四 — четыре уровня понимания каждого текста.
