# Игра Го (圍棋)

Вэйци (圍棋, «игра в окружение») — настольная стратегическая игра, в которой два игрока по очереди выставляют камни на пересечениях сетки, стремясь окружить и захватить territory соперника. Один из древнейших примеров формализованной модели территориального контроля.

## Место в структуре 井

Игра Го является практикой чтения поля. Она показывает управленческий код через территорию, окружение, баланс времени и цену каждого хода — прикладную модель тех же принципов, что организуют решётку 井: позиция важнее отдельного действия, а влияние распределяется постепенно.
