# Шесть секретных учений (六韜)

«Шесть секретных учений» (Лю Тао) — один из семи классических военных трактатов Китая, приписываемый Тай-гуну (Цзян Цзыя), советнику Вэнь-вана и У-вана, основателей династии Чжоу.

Состоит из 6 частей:

1. **Гражданское секретное учение** — управление государством, привлечение мудрецов
2. **Военное секретное учение** — стратегия и тактика наступления
3. **Секретное учение дракона** — организация армии, роль полководца
4. **Секретное учение тигра** — снаряжение, сражения, переходы
5. **Секретное учение леопарда** — бой на различной местности
6. **Секретное учение собаки** — рода войск, особенности их применения
