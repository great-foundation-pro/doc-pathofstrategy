### КНИГА III

#### ПОМОЩНИК ОБЩЕГО УПРАВИТЕЛЯ (СЯО-ЦЗАЙ 小宰)

1. Сей чиновник обязан установить наказания дворцов царства, с тем чтобы направлять высшее начальствование дворцом государя, контроль и запреты, касающиеся всех дворцов [^113].

<!-- PAGE 169 -->

Он направляет во вторую очередь введение в действие шести уложений, восьми уставов, восьми статутов, дабы контролировать управление всех чиновников в царствах и княжествах, уделах и волостях, назначенных для содержания должностей. Он направляет во вторую очередь исполнение девяти видов дани, девяти видов налогов, девяти мер, или пропорций, дабы уравнивать поступления и упорядочивать расходы государства.

Посредством шести разрядов порядка высших чиновников он упорядочивает всех чиновников.

Во-первых, он определяет по разряду порядка их места на великих присутствиях двора [^114].

Во-вторых, он представляет по разряду порядка их управления [^115].

В-третьих, он упорядочивает по разряду порядка их службы [^116].

<!-- PAGE 170 -->

В-четвёртых, он определяет по разряду порядка их содержание [^117].

В-пятых, он принимает по разряду порядка общие отчёты [^118].

В-шестых, он выносит решения по разряду порядка по их спорам [^119].

Посредством шести ведомств высших чиновников он усовершает правление государства.

Он различает [^120]:

Во-первых, министерство неба. Чиновников, от него зависящих, числом шестьдесят. Они занимаются правлением, или должностной администрацией. Для служб высшего порядка они подчиняются своим особым начальникам [^121]. Для служб низшего порядка они действуют сами по себе, по отдельности [^122].

<!-- PAGE 171 -->

Во-вторых, министерство земли. Чиновников, от него зависящих, числом шестьдесят. Они занимаются должностным наставлением. Для служб высшего порядка они подчиняются своим особым начальникам. Для служб низшего порядка они действуют сами по себе, по отдельности.

В-третьих, министерство весны. Чиновников, от него зависящих, числом шестьдесят. Они занимаются должностными обрядами. Для служб высшего порядка они подчиняются своим особым начальникам. Для служб низшего порядка они действуют сами по себе, по отдельности.

В-четвёртых, министерство лета. Чиновников, от него зависящих, числом шестьдесят. Они занимаются должностным начальствованием, или исполнительной властью. Для служб высшего порядка они подчиняются своим особым начальникам. Для служб низшего порядка они действуют сами по себе, по отдельности.

В-пятых, министерство осени. Чиновников, от него зависящих, числом шестьдесят. Они занимаются должностными наказаниями. Для служб высшего порядка они подчиняются своим особым начальникам. Для служб низшего порядка они действуют сами по себе, по отдельности.

<!-- PAGE 172 -->

В-шестых, министерство зимы. Чиновников, от него зависящих, числом шестьдесят. Они занимаются должностными работами. Для служб высшего порядка они подчиняются своим особым начальникам. Для служб низшего порядка они действуют сами по себе, по отдельности [^123].

Посредством шести административных направлений высших чиновников он разделяет правление государства [^124].

Первое есть направление правления, или общей администрации. Оно создано для поддержания спокойствия в царствах, для уравнивания населений, для упорядочения административных поступлений и расходов.

Второе есть направление нравственного и политического наставления.

<!-- PAGE 173 -->

Оно создано для укрепления царств, для закрепления населений, для исполнения обязанностей в отношении посетителей двух разрядов [^125].

Третье есть направление обрядов. Оно создано для обеспечения единения царств, для поддержания согласия между населениями, для совершения церемоний в честь духов и гениев.

Четвёртое есть направление исполнительной власти. Оно создано для приведения к повиновению царств [^126], для образования населений к деятельным службам, для собирания ста предметов, необходимых для походов.

Пятое есть направление наказаний. Оно создано для исправления царств, для удержания населений в долге, для изгнания воров и разбойников.

Шестое есть направление работ. Оно создано для обеспечения нужд царств, для прокормления

<!-- PAGE 174 -->

населений, для произведения ста предметов, необходимых населениям [^127].

Посредством шести связей, или общих служб высших чиновников [^128], он объединяет различные отрасли правления государства.

Первая есть общая служба жертвоприношений [^129].

Вторая есть общая служба приёма посетителей первого и второго разряда [^130].

<!-- PAGE 175 -->

Третья есть общая служба погребений и голодных времён [^131].

Четвёртая есть общая служба наборов войск и походов.

Пятая есть общая служба повинностей и великих охот [^132].

Шестая есть общая служба по взиманию налогов, по освобождению от налогов [^133].

<!-- PAGE 176 -->

Вообще, службы низшего порядка все имеют связи между собою [^134].

Посредством восьми правил действия чиновников [^135] он упорядочивает правление государства.

Во-первых, выносится решение о применении налога и повинностей на основании групп из пяти дворов [^136].

Во-вторых, выносится решение о наборах войск и

<!-- PAGE 177 -->

о сопровождениях великих охот на основании реестров осмотра и счётов [^137].

В-третьих, выносится решение о делах волостей и селений на основании реестров населения и планов местностей [^138].

В-четвёртых, выносится решение о делах займов на основании договора, разделённого надвое [^139].

В-пятых, выносится решение о спорах относительно

<!-- PAGE 178 -->

жалованья и рангов на основании обрядов и указов [^140].

В-шестых, выносится решение о претензиях относительно выданного и полученного на основании письменного соглашения [^141].

В-седьмых, выносится решение о претензиях относительно

<!-- PAGE 179 -->

продаж и покупок на основании удостоверительных записей, или расписок [^142].

В-восьмых, выносится решение о претензиях относительно поступлений и выдач продуктов [^143] на основании месячных и годовых счётов [^144].

<!-- PAGE 180 -->

Рассматривая шесть проверок чиновников, он разлагает, или разбирает в подробностях, управление различных чиновников [^145].

Сии шесть проверок охватывают:

Во-первых, честность и послушание [^146].

Во-вторых, честность и способность.

В-третьих, честность и бдительность над собою.

В-четвёртых, честность и прямота поведения.

В-пятых, честность и соблюдение законов [^147].

В-шестых, честность и рассудительность [^148].

Посредством особых постановлений он занимается предписанием и приготовлением [^149] всего, что относится к жертвоприношениям, великим собраниям при дворе в четыре времени года и к приёмам посетителей. Когда бывает собрание войска, повинность великой охоты, погребальная служба

<!-- PAGE 181 -->

(по императору), голод, он действует так же. Для сих семи видов великих должностных действий он приказывает, чтобы высшие чиновники предъявляли, или сообщали, средства, назначенные на их должность. Он упорядочивает распространение их милостей (освобождений от служб, ими даруемых). Он выслушивает и судит тяжбенные споры относительно их управления.

Вообще, при жертвоприношениях он помогает подносить яшму, драгоценные предметы, сосуд; он помогает совершать возлияния [^150].

Вообще, при приёмах иноземных посетителей он помогает при совершении возлияний. Он помогает, когда государь принимает сосуд, когда государь принимает драгоценные предметы [^151].

<!-- PAGE 182 -->

При великих погребениях он получает поручение поместить драгоценные предметы в уста умершего и поднести покров. Во времена голода он получает поручение давать шёлковые ткани и яшму посетителям, получающим вспоможение от двора [^152].

В конце каждой луны, сообразно порядку рангов, назначенных высшим чиновникам, он принимает краткие отчёты всех чиновников. Он также помогает великому управителю принимать годовые отчёты [^153].

В конце года он приказывает чиновникам представить общий счёт их действий.

В начале правильного года [^154] он становится во главе всех чиновников министерства общей администрации

<!-- PAGE 183 -->

и рассматривает с ними таблицы уставов управления. Он совершает обход с колокольчиком с деревянным язычком и говорит: «Правление имеет обычные наказания для тех, кто не сообразуется с законами».

Он возвращается и, взяв таблицы наказаний дворца, выставляет эти запретительные постановления в императорском дворце [^155]. Он возвещает их ста высшим чиновникам [^156] и говорит: «Да соблюдает каждый из вас свои обязанности, рассматривает свой устав, исполняет свои должности. Повинуйтесь так наказу, который даёт вам государь. Если же есть такие, кто непочтителен к его повелениям, правление имеет для них великие наказания [^157]».

<!-- PAGE 184 -->

#### ЗАМЕСТИТЕЛЬ ОБЩЕГО УПРАВИТЕЛЯ (ЦЗАЙ-ФУ 宰夫)

Сей чиновник занимается устроением присутствия общего управления, дабы упорядочивать места государя, трёх великих советников, шести министров, префектов и различных чиновников; вообще, он занимается запретами и предписаниями, касающимися сего торжества [^158].

Он распределяет по разрядам должности различных чиновников, дабы ожидать повелений, даваемых иноземными посетителями, ответов, приносимых уполномоченными чиновниками, требований, представляемых людьми народа [^159].

Он занимается разделением повелений и приказаний,

<!-- PAGE 185 -->

присвоенных ста чиновникам. Он различает восемь степеней административного подчинения [^160].

Первую степень составляют титулярные начальники [^161]. Они занимаются должностными уставами для направления совокупности служб.

Вторую степень составляют руководители [^162]. Они занимаются должностными правилами действия для направления общих положений.

Третью степень составляют высшие заведующие [^163]. Они занимаются должностными уставами для направления подробностей.

Четвёртую степень составляют рядовые чиновники [^164].

<!-- PAGE 186 -->

Они занимаются обычными правилами должностного управления для направления численностей людей, предметов [^165].

Пятую степень составляют хранители складов. Они занимаются оправдательными документами должностного управления для направления сохранения письменных дел и предметов [^166].

Шестую степень составляют писари. Они занимаются должностными письменными делами для вспоможения действиям управления [^167].

Седьмую степень составляют помощники. Они занимаются должностной организацией для направления внутреннего порядка различных служб [^168].

Восьмую степень составляют служители. Они занимаются должностными повелениями для призывания чиновников и передачи приказов [^169].

Он занимается уставами общего управления,

<!-- PAGE 187 -->

для рассмотрения управления ста высших чиновников [^170] и заведующих земельными округами и владениями, назначенными для содержания должностей [^171]. Он исчисляет поступление и выдачу продуктов, которые они расходуют. Вообще, тех, кто теряет эти продукты или делает из них незаконное употребление, кто скрывает дурно израсходованные продукты или делает ложные записи [^172], — он наказывает их по должностным наказаниям, предупредив великого управителя (Чжун-цзай). Тех, кто пользовался продуктами бережливо, кто имеет остаток от сих продуктов, кто сохранил их в добром состоянии [^173], — он награждает.

Согласно уставам о пропорциях [^174], он занимается приготовлениями и предписаниями, касающимися жертвоприношений, а также приношений и яств, представляемых в этих церемониях [^175]. Он сопровождает великого управителя и присутствует при омовении и очищении сосудов.

Вообще, при всех обрядовых церемониях он помогает

<!-- PAGE 188 -->

помощникам управителя и рассматривает с ними распоряжения, касающиеся высших чиновников [^176].

Вообще, когда феодальные князья совершают посещения четырёх времён года; когда они собираются при дворе в великом собрании; когда прибывают посетители первого или второго разряда, сообразно уставу обряда жертв, он занимается поставками, им присвоенными, таковыми как обряд жертв, съестные припасы на их пути, приношения изысканных яств, трапезы, где они пьют и едят, драгоценные подарки. Он занимается распоряжениями и числовыми количествами [^177].

Вообще, когда бывает служба должностных утешений, он занимается её упорядочением. Он также занимается драгоценными предметами, сосудами, или утварью, предназначенными для погребений; вообще, всем, что поставляется [^178].

При великих и малых погребениях [^179] он занимается

<!-- PAGE 189 -->

наставлениями, касающимися малых чиновников [^180]. Он становится во главе начальников служб и направляет их. При погребениях трёх великих советников, шести министров он присоединяется к распорядителю погребений [^181], становится во главе чиновников, состоящих на службе, и направляет их. При погребениях префектов он приказывает своим второстепенным чиновникам, или низшим выпускникам, стать во главе тех, кто состоит на службе, и направлять их.

В конце года [^182] он приказывает различным чиновникам приготовить годовые отчёты. В конце каждой луны он приказывает им приготовить месячные отчёты. В конце каждой декады он приказывает им приготовить ежедневные ведомости и при помощи сих документов рассматривает их управление. Тех, кто в своём управлении не сообразуется с назначенными сроками [^183], он отмечает перед великим управителем и наказывает их.

В начале года он привлекает внимание чиновников к уставам управления. Он приказывает упорядочить особые службы внутренних покоев дворца. Он записывает тех, кто способен и кто ведёт себя

<!-- PAGE 190 -->

хорошо. Он отмечает их перед своими начальниками (великим управителем и помощником общего управителя) [^184].

## СНОСКИ

[^1]: Согласно комментарию B, это предисловие относится к основанию Ло-яна Чжоу-гуном. «Чжоу-гун, — говорит он, — составил шесть великих административных уложений, чтобы дать их Чэн-вану, и основал Ло-и (или Ло-ян) посреди земли, чтобы управлять всем миром. В самом деле, читаем в статье о Да-сы-ту, начальнике второго министерства, что точка, определённая этим чиновником как центр императорского царства, есть середина земли, точка соединения неба и земли, место, где соединяются четыре времени года, ветер и дождь, начала покоя и движения».

[^2]: Комм. B. Он определяет четыре стороны света наблюдением солнца и полярной звезды. См. статью о Цзян-жэнь, книга XLIII «Чжоу-ли».

[^3]: То есть местоположение главных административных делений царства от столицы до границы. Этот смысл, данный издателями, наиболее правдоподобен. Комм. B и Ван-ань-ши говорят, что государь устанавливает положения зала предков, места, посвящённого гениям земли и злаков, императорского дворца и общественного рынка. Эти подробности лучше относятся к следующей фразе.

[^4]: Комм. C. Го (国), царство, обозначает здесь столицу, центральный город. Е (野), земли вне города, обозначает территорию вне этого города.

[^5]: Комм. B. Он определяет шесть административных ведомств и упорядочивает должности их чиновников.

[^6]: Комм. Чжу-си. Цзи (极), вершина, обозначает центр всех вещей, цель, к которой должно обращаться со всех сторон, чтобы получить благое направление.

[^7]: Комм. B. Небо устрояет все вещи. Сын неба (император) учреждает великого управителя, повелевает ему взять в руки управление государством. Так он устрояет всех чиновников по подобию порядка, установленного небом. Отсюда его имя — министр неба, Тянь-гуань (天官). Гуань (官) означает одновременно и должность, и чиновника, так что то же выражение Тянь-гуань, поставленное во главе этой главы, должно переводиться как министерство неба. Текст не даёт Чжун-цзаю, или великому управителю, названия министра (Цзин 卿), но это звание подразумевается, как это видно из комментария.

[^8]: Комм. C. Бан-го (邦国); это собирательное выражение обозначает здесь феодальные княжества. Когда текст употребляет раздельно тот или другой из этих знаков, он обозначает в общем царство государя. Когда он говорит: царство государя, Ван-го (王国), он, по-видимому, обозначает это царство одно, без феодальных княжеств.
