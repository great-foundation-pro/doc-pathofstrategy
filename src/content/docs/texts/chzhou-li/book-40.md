## КНИГА XL. 459

7 В стране Юэ [Youe], если нет мотыги, без нее нельзя обойтись для возделывания земли. Любой человек может там делать мотыги. В стране Янь [Yen], если нет доспехов, без них нельзя обойтись для защиты. Любой человек может там делать доспехи. В стране Цинь [Thsin], если нет древка для пики, без него нельзя обойтись. Любой человек может там делать древки для пик. Среди северных кочевников, если нет ни лука, ни колесницы, без них нельзя обойтись. Любой человек может там делать луки и колесницы [1].

8 Мудрые люди изобретают [2]. Искусные люди продолжают то, что начали первые. Те, кто сохраняет из поколения в поколение открытые таким образом способы, являются ремесленниками.

Все операции, выполняемые ста ремесленниками, являются творением мудрецов [3].
