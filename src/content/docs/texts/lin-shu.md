# Лин Шу (靈樞) — Ось духа

Вторая часть «Трактата Жёлтого императора о внутреннем» (Хуан-Ди нэй-цзин). 81 раздел посвящён иглоукалыванию, меридианам, точкам-шу и циркуляции энергии ци. Перевод Б.Б. Виногродского.
