# Три стратегии Хуан Ши-гуна (黃石公三略)

Один из семи классических военных трактатов Китая. Приписывается Князю Жёлтой скалы (Хуан Ши-гун), легендарному наставнику Чжан Ляна. Состоит из трёх частей:

- **Высшая стратегия** — принципы управления, мягкость и твёрдость
- **Срединная стратегия** — искусство полководца, единство власти
- **Низшая стратегия** — признаки упадка, предупреждение угроз
