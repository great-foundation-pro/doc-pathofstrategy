# Обозначение Дао (道名)

Тема именования восходит к первой строке «Дао Дэ Цзин»: «Дао, которое может быть названо, не есть постоянное Дао; имя, которое может быть дано, не есть постоянное имя» (道可道，非常道；名可名，非常名). Вопрос обозначения — это вопрос о границе между тем, что структура может зафиксировать словом, и тем, что ускользает от фиксации.

## Место в структуре 井

Обозначение Дао показывает, что управление требует точных имён: название фиксирует функцию, функция задаёт место, место делает систему воспроизводимой. Без точного языка обозначений колодезная решётка 井 осталась бы геометрией без смысла.
