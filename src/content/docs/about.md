# О проекте

Проект «Путь Стратегии» (Path of Strategy) — независимое исследование корпуса из ~30 древнекитайских классических текстов, объединённых в единую систему на основе космологии У-Син (五行).

## Методология

Каждый текст изучается через четыре уровня понимания:

1. **Форма** (形) — структура и композиция
2. **Содержание** (意) — смысл и идеи
3. **Связи** (通) — отношения с другими текстами
4. **Применение** (用) — практическое использование
